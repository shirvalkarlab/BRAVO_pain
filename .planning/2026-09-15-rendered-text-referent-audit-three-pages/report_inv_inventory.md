2. **`BiomarkerAnalytics.js`'s `chPanels` array.** Six panels ("ROC curve…", "Honest performance…", "Power vs \<pain\> correlation…", "Power band-power distribution…", "Sliding-window performance over time…", the freq-binarization panel) are fully built with real, formatted titles at lines 509-1193, but `chPanels` is never read by the file's own return statement — only `tdPanels` is rendered. 3. **Whether a passing device rule's full wording is reachable anywhere.** I traced that `Rule.human_text` reaches the page only via `row.why`, and that `why` appears to be assembled only for violated/advisory/deferred rule outcomes in `constraints.py` (L2710-2751). I did not find the code path that would attach a `why`/detail sentence to a *satisfied* rule, but I also did not exhaustively read every call site in `pipeline.py` that builds the ledger's "recorded values" bucket, so I cannot rule out a second path that does surface it there.
